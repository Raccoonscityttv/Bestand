GitHub-Synchronisierung
Der Bestand liegt dann in einem privaten GitHub-Repository und ist auf allen Geräten gleich.
Token und Repository einrichten
  1. Auf github.com ein neues, privates Repository anlegen (z. B. bestand-daten), mit „Add a README file“.
  2. Unter Settings → Developer settings → Personal access tokens → Fine-grained tokens → „Generate new token“.
  3. „Repository access“: Only select repositories und nur das Daten-Repository wählen.
  4. Unter „Permissions“ → Repository permissions → Contents: Read and write.
  5. Laufzeit wählen (maximal 1 Jahr), Token erzeugen, kopieren und oben einfügen. Er wird nur auf diesem Gerät gespeichert.
Auf jedem Gerät die gleichen Angaben eintragen.
